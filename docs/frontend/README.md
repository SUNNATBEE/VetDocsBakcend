# Vet Clinic Frontend Docs

Bu bo'lim frontend jamoasi uchun yagona professional hujjatlar to'plami.

## Kim uchun

- Frontend developerlar
- Tech lead
- QA
- PM / loyiha menejeri

## Hujjatlar ro'yxati

1. [`FRONTEND_ARCHITECTURE.md`](./FRONTEND_ARCHITECTURE.md)
   - Tizim arxitekturasi, qatlamlar, papka dizayni, state boshqaruvi.
2. [`FRONTEND_API_INTEGRATION.md`](./FRONTEND_API_INTEGRATION.md)
   - Backend bilan ishlash standarti, token flow, endpoint mapping, error handling.
3. [`FRONTEND_DELIVERY_PLAN.md`](./FRONTEND_DELIVERY_PLAN.md)
   - Sprintlar, team ownership, DoD, PR va release tartibi.

## Tez start

1. Avval `FRONTEND_ARCHITECTURE.md`ni o'qing.
2. Keyin `FRONTEND_API_INTEGRATION.md`dagi API contract'ni joriy qiling.
3. Ishni `FRONTEND_DELIVERY_PLAN.md` bo'yicha sprintlarga bo'lib bajaring.
